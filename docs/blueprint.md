# **App Name**: Vela Fortaleza

## Core Features:

- Intelligent Navigation Hub: A high-performance interactive map featuring real-time user location, zoom support, and specialized markers for the 'Terra da Luz' highlights.
- AI Personal Concierge: An AI-powered tool that acts as a personalized guide, using reasoning to recommend specific Ceará dishes or attractions based on the user's current mood and history.
- Universal Localization Engine: One-tap switching between English, Portuguese, Spanish, and French across all interface elements and content.
- Resilient Offline Core: Advanced data persistence for attractions, restaurant details, and images, ensuring functionality during patchy network connectivity at remote beach locations.
- Curated Spotlight Gallery: Immersive glassmorphism cards featuring high-resolution visuals of spots like Praia do Futuro and Mercado Central, with deep-link navigation.
- Smart Favorites Collection: Persistent local storage for user-saved locations and custom travel bucket lists available across sessions.
- Transit Bridge: One-tap integration that hands off coordinates directly to Apple Maps or Google Maps for live driving or walking routes.

## Style Guidelines:

- Primary color: Electric Sky Blue (#53beec) to reflect the vibrant Fortaleza coastline.
- Background color: Deep Atlantic Midnight (#0f1315), providing a premium, high-contrast dark theme environment.
- Accent color: Ultra Violet (#8c8cff), used sparingly for highlights and active navigation states.
- Headline font: 'Playfair', a modern high-contrast serif for an elegant, premium feel. Body font: 'Inter', a clean sans-serif for optimal readability on mobile.
- Minimalist, thin-stroke monochrome icons to maintain a sophisticated professional aesthetic.
- Mobile-first, vertically oriented card architecture featuring subtle glassmorphism and ample negative space.
- Liquid transitions between content states and gentle parallax effects on attraction image headers.
